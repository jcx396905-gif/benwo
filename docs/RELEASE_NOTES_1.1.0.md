# 本我 1.1.0

本版本改为无账户的单用户本地模式，并带来米色瓷面、锤子式分组组件和亮暗主题。

重要：从旧版本首次升级到 1.1.0 时，应用会一次性且不可恢复地清空旧账号、目标、待办、画像、设置和遗留通知。完成重置后会显示精简画像引导；可以填写三项可选偏好，也可以完全跳过并直接进入首页。之后不会再次自动清空数据。

- 删除登录、注册、密码、会话与账号设置。
- 画像精简为沟通风格、最佳工作时间和任务节奏，可在设置中编辑或清空。
- 新增跟随系统、亮色和暗色三档主题。
- 全局移除绿色主色，改为米色、金铜与陶土色。
- 画像数据仅在主动使用 AI 目标拆解时随目标文本发送；未填写的偏好不会发送。主动使用番茄 AI 规划时，只发送当次输入的计划描述。
- 恢复旧版番茄钟：每日计划、计时与休息、暂停续跑、统计历史和保存清单均已接回单用户架构。
